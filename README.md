# เช็คเอง · ครูพละ

แอป HTML/CSS/JavaScript ใช้ IndexedDB บันทึกในอุปกรณ์, Service Worker เปิดออฟไลน์, Apps Script ซิงก์ข้อมูลแบบตรวจ revision ก่อนเขียนและรายงาน Google Sheets

## เปิดบน Mac

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

เปิด http://localhost:8765 ใช้ origin เดิมทุกครั้ง รายละเอียดติดตั้งและ Google Sheets อยู่ใน SETUP.html

## สิ่งที่ทำได้

- เพิ่ม/แก้ห้อง นักเรียนรายคนหรือวางหลายคน แยกวิชาสุขศึกษา/พลศึกษา
- นำเข้านักเรียนจาก Excel (.xlsx) / CSV UTF-8 ที่เมนูนักเรียน พร้อมไฟล์ตัวอย่างและหน้าตรวจรายชื่อก่อนยืนยัน; รหัสซ้ำ/ข้อมูลไม่ครบจะไม่บันทึกทั้งชุด
- เช็กชื่อแยกวันที่และคาบ เก็บฉบับร่างอัตโนมัติ ต้องครบและกดบันทึกคาบก่อนนับเวลาเรียน
- แก้ย้อนหลัง, ย้ายออกโดยเก็บประวัติ, เพิ่มงาน/คะแนนเต็ม/คัดลอกงานข้ามห้องชั้นเดียวกัน
- คะแนนทศนิยม ว่างคิด 0 สัดส่วน 60/10/10/20 เกณฑ์เกรดแก้ได้ และ มส. ต่ำกว่า 80%
- ตารางสอนรายสัปดาห์, บันทึกสิ่งที่สอน, รายงาน/CSV/พิมพ์, ภาคเรียนและคัดลอกรายชื่อ
- สำรอง/กู้คืน JSON, กู้ชุดก่อนนำเข้า, บันทึกประวัติแก้ไขล่าสุด 500 รายการ
- ซิงก์อัตโนมัติเมื่อแอปเปิดและออนไลน์ หลังตั้งค่า Apps Script; หากแก้สองเครื่องพร้อมกันให้เลือกชุดข้อมูล ไม่ทับเงียบ

## สถานะที่ต้องตั้งค่าจริง

ยังไม่มี deployment HTTPS และยังไม่ผูกบัญชี Google ของผู้ใช้ ต้อง Deploy Apps Script ใน Sheets ส่วนตัวและใส่ URL/รหัสเชื่อมต่อในแอป ไม่มีข้อมูลลับฝังในโค้ด
การทดสอบ backend ในเครื่องใช้บริการ Google จำลอง ยังต้องทดสอบการอนุญาตและ HTTP จริงหลัง deployment
การเชื่อมต่อ Apps Script ใช้ HTTPS POST text/plain และรอ JSON ตอบกลับ ไม่ใช้ no-cors (ไม่ถือว่าส่งสำเร็จถ้ายังไม่ได้รับการยืนยัน)

## โครงสร้าง

- `core.js`: การคำนวณ, ตรวจข้อมูลนำเข้า, รายงาน (ใช้ร่วมกับ backend)
- `app.js`: UI, IndexedDB, การสำรอง และ client sync
- `student-import.js`: อ่านไฟล์ในเครื่อง ตรวจหัวคอลัมน์ รายชื่อ และเลขประจำตัวซ้ำ
- `templates/`: ไฟล์ตัวอย่าง Excel และ CSV (รายชื่อสมมติ)
- `vendor/`: SheetJS CE 0.20.3 จาก cdn.sheetjs.com พร้อมใบอนุญาต Apache-2.0 เพื่ออ่าน Excel แบบออฟไลน์
- `google-apps-script/Code.gs`: ตรวจรหัส/ล็อก/CAS/สำรองสองช่อง/สร้างรายงาน
- `google-apps-script/Core.gs`: สำเนา core.js; คัดลอกใหม่ทุกครั้งที่แก้กติกา
- `prototype.html`: ต้นแบบเดิมก่อนเริ่มระบบจริง
- `tests/`: Node built-in tests สำหรับกติกาและสัญญา backend

## ทดสอบ

```sh
node --test tests/*.test.cjs
node --check app.js
```

อัปเดตเว็บให้เพิ่มเวอร์ชัน CACHE ใน sw.js และ deploy ไฟล์พร้อมกัน Service Worker รุ่นใหม่จะใช้งานหลังปิดแท็บแอปรุ่นเก่าทั้งหมดแล้วเปิดใหม่ ไม่ใช้ skipWaiting ระหว่างกรอกข้อมูล
