เริ่มใช้เช็คเอง

อัปเดตจากระบบเดิม

ระบบใหม่นำเข้ารายชื่อก่อนสร้างวิชา หากเชื่อม Google Sheets อยู่ ให้แทนโค้ดทั้ง Code.gs และ Core.gs ด้วยไฟล์ชุดใหม่ แล้วไป Deploy → Manage deployments → Edit → New version → Deploy ใช้ URL และรหัสเชื่อมต่อเดิมได้ ไม่ต้องรัน setup ใหม่

ดาวน์โหลด Code.gs · ดาวน์โหลด Core.gs
ตัวแอปบันทึกข้อมูลในเครื่องได้แล้ว การติดตั้งบน iPhone ต้องเปิดจากเว็บไซต์ HTTPS และ Google Sheets ต้องตั้งค่าครั้งแรกก่อน

ใช้งานบน MacBook

  1. เปิด Terminal ในโฟลเดอร์แอป แล้วรัน python3 -m http.server 8765 --bind 127.0.0.1
  2. เปิด localhost:8765 ใน Safari หรือ Chrome
  3. นำเข้าไฟล์เลขที่ / ชื่อ-นามสกุล / ชั้น → ระบบแยกห้อง → สร้างวิชาและเลือกห้องที่เรียน → วันที่และคาบ → เช็กชื่อให้ครบ → บันทึกคาบ
  4. เพิ่มงานในเมนูงาน/ชิ้นงาน แล้วกรอกคะแนนในสมุดคะแนน

ใช้ที่อยู่เว็บเดิมและเบราว์เซอร์เดิมเพื่ออ่านข้อมูลในเครื่องชุดเดิม การเปิดผ่าน file:// เป็นคนละพื้นที่ข้อมูลกับ localhost หรือเว็บไซต์จริง ให้สำรองก่อนย้ายที่อยู่เว็บ

ติดตั้งบน iPhone

  1. นำไฟล์ index.html, styles.css, core.js, app.js, sw.js, manifest.webmanifest, icon.svg, icon-192.png, icon-512.png และ SETUP.html ขึ้นโฮสต์แบบ HTTPS ในโฟลเดอร์เดียวกัน
  2. เปิด URL ใน Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม
  3. เปิดแอปครั้งแรกขณะมีเน็ตให้โหลดไฟล์ครบ จากนั้นใช้เช็กชื่อและกรอกคะแนนออฟไลน์ได้
  4. ตั้งค่า URL และรหัสเชื่อมต่อเดียวกับ MacBook แล้วกดดึงข้อมูลจาก Sheets

การซิงก์ทำงานขณะเปิดแอป เมื่อปิดแอปหรือไม่มีเน็ต ข้อมูลยังอยู่ในอุปกรณ์และรอซิงก์ ไม่สามารถรับประกันการซิงก์ขณะ iPhone ล็อกหน้าจอ

ตั้งค่า Google Sheets ครั้งแรก

  1. สร้าง Google Sheets ส่วนตัวสำหรับเช็คเองโดยเฉพาะ
  2. ไปที่ ส่วนขยาย → Apps Script
  3. นำโค้ดจากไฟล์ Code.gs ใส่ในไฟล์ Code.gs และสร้างไฟล์ Core.gs จาก Core.gs
  4. เลือกฟังก์ชัน setup แล้วกด Run อนุญาตบัญชี Google ของครู ฟังก์ชันจะผูก Spreadsheet ปัจจุบันและสร้างรหัสเชื่อมต่อ 64 ตัวใน Execution log
  5. Deploy → New deployment → Web app → Execute as: Me → Who has access: Anyone → Deploy
  6. คัดลอก Web app URL ที่ลงท้าย /exec และรหัสเชื่อมต่อ ใส่ในแอป → ตั้งค่า → Google Sheets
  7. กดบันทึกการเชื่อมต่อ และซิงก์ตอนนี้จนแสดง “สำรองแล้ว”
Web App เปิดรับคำขอจากอุปกรณ์ที่มีรหัสเชื่อมต่อเท่านั้น ตัว Sheets ไม่ต้องแชร์สาธารณะ เก็บรหัสนี้เป็นส่วนตัว และใส่รหัสเดียวกันบน iPhone กับ MacBook

ถ้าบัญชีโรงเรียนไม่อนุญาต Deploy แบบ Anyone ต้องให้ผู้ดูแลเปิดสิทธิ์หรือใช้บัญชีที่อนุญาตตามนโยบายโรงเรียน การเชื่อมต่อจริงยังต้องตรวจหลัง Deploy ในบัญชีของครู

Sheets จะมีแท็บเช็คเอง_คะแนน, เช็คเอง_เวลาเรียน และเช็คเอง_งาน สำหรับดู/คัดลอกไป Excel ข้อมูลสำรองเต็มอยู่ในแท็บซ่อน _CHECKENG_A/B ให้แก้ข้อมูลผ่านแอป เพราะแท็บรายงานสร้างใหม่เมื่อซิงก์

ระบบตรวจเวอร์ชันก่อนบันทึก ถ้าสองเครื่องแก้ข้อมูลออฟไลน์พร้อมกัน แอปให้เลือกข้อมูลทั้งชุดและดาวน์โหลดอีกชุดเก็บไว้ การรวมความเปลี่ยนแปลงสองชุดยังต้องทำเองหลังเลือก

สำรองด้วยไฟล์

ตั้งค่า → ดาวน์โหลดไฟล์สำรอง เก็บข้อมูลครบทุกเทอมโดยไม่รวมรหัสเชื่อมต่อ เมื่อกู้คืน ระบบตรวจไฟล์และเก็บชุดเดิมไว้ที่ “กู้คืนก่อนนำเข้าล่าสุด” ด้วย

วิธีคิดคะแนน

  • ระหว่างเรียน = คะแนนงานรวม ÷ คะแนนเต็มงานรวม × 60
  • เข้าเรียน = คาบมา/ลา/สาย ÷ คาบที่เช็กครบ × 10
  • กลางภาค = คะแนนที่ได้ ÷ คะแนนเต็มกลางภาค × 10
  • ปลายภาค = คะแนนที่ได้ ÷ คะแนนเต็มปลายภาค × 20
  • ช่องว่าง = 0; คะแนนเก็บทศนิยมเต็มและแสดงไม่เกินสองตำแหน่ง
  • เวลาเรียนต่ำกว่า 80% ให้ มส. หากไม่มีคาบที่เช็กครบ เกรดแสดง — จนมีข้อมูลเวลาเรียน

เอกสารอ้างอิง: Apps Script Web Apps · LockService · Content Service

นำเข้ารายชื่อนักเรียนจากไฟล์

เปิดเมนู นักเรียน → เลือกห้อง → นำเข้าจากไฟล์ แล้วดาวน์โหลด ตัวอย่าง Excel หรือ ตัวอย่าง CSV

  1. แทนที่รายชื่อสมมติด้วยรายชื่อจริง คงหัวคอลัมน์ เลขประจำตัว และ ชื่อ–นามสกุล ไว้ในแถวแรก
  2. ตั้งเลขประจำตัวเป็นข้อความเพื่อรักษาเลขศูนย์ด้านหน้า และบันทึก CSV เป็น UTF-8
  3. เลือกไฟล์ หากมีหลายชีตให้เลือกชีตที่ต้องการ ตรวจรายชื่อก่อนกดยืนยัน
  4. ถ้ามีรหัสซ้ำหรือข้อมูลไม่ครบ ให้แก้ไฟล์แล้วเลือกใหม่ ระบบจะยังไม่เพิ่มรายชื่อจนกว่าจะถูกต้องทุกแถว

รองรับ .xlsx และ .csv ไม่เกิน 5 MB / 2,000 แถว รายชื่อเพิ่มในห้องที่เลือก ใช้ร่วมกันทั้งสองวิชา คาบเก่ายังคงรายชื่อเดิม
